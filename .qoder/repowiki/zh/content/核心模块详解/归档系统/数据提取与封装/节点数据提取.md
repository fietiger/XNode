## 项目结构

本项目采用模块化架构，核心功能分布在多个子系统中。节点数据提取功能主要涉及`XNode`主项目中的`ArchiveSystem`（存档系统）和`NodeEditSystem`（节点编辑系统），以及基础库`XLib.Node`。

## 节点数据提取流程

`Extracter`类的`FillNodeList`方法负责遍历`WM.Main.Editer.NodeList`中的节点实例，并将其转换为可序列化的`NodeData`对象。该方法首先通过`WM.Main.Editer.NodeList`获取当前编辑器中的所有节点，然后对每个节点进行数据提取和转换。

```mermaid
flowchart TD
Start([开始提取节点数据]) --> GetNodeList["获取 WM.Main.Editer.NodeList"]
GetNodeList --> LoopStart{"遍历节点列表"}
LoopStart --> ProcessNode["处理单个节点"]
ProcessNode --> CreateBaseData["创建 NodeBaseData 实例"]
CreateBaseData --> ExtractTypeString["调用 GetTypeString() 获取类型字符串"]
ExtractTypeString --> GetParaDict["调用 GetParaDict() 获取参数字典"]
GetParaDict --> GetPropertyDict["调用 GetPropertyDict() 获取属性字典"]
GetPropertyDict --> CreateNodeData["创建 NodeData 实例"]
CreateNodeData --> SerializeNode["序列化 NodeData 为 JSON 字符串"]
SerializeNode --> AddToList["添加到 Data_1_0.NodeList"]
AddToList --> LoopEnd{"是否还有更多节点?"}
LoopEnd --> |是| LoopStart
LoopEnd --> |否| End([完成节点数据提取])
```

`NodeBaseData`类负责封装节点的基本信息，包括`NodeLibName`、`TypeString`、`Version`、`ID`和`Point`。这些信息通过`ToString()`方法以特定格式序列化为字符串，格式为`NodeLibName/TypeString/Version/ID/Point`。

## ParaDict与PropertyDict生成机制

`ParaDict`和`PropertyDict`字典通过节点的`GetParaDict()`和`GetPropertyDict()`方法获取。`GetParaDict()`是抽象方法，必须由具体节点类实现，用于返回节点的参数字典。`GetPropertyDict()`是虚方法，默认返回空字典，可由子类重写以提供自定义属性。

```mermaid
sequenceDiagram
participant Extracter as Extracter
participant Node as NodeBase
participant ConcreteNode as 具体节点类
Extracter->>Node : GetParaDict()
alt 抽象方法
Node-->>ConcreteNode : 调用重写方法
ConcreteNode-->>Node : 返回参数字典
end
Node-->>Extracter : 返回参数字典
Extracter->>Node : GetPropertyDict()
alt 虚方法
Node-->>Node : 返回默认空字典
Note over Node : 可由子类重写
end
Node-->>Extracter : 返回属性字典
```

## JSON序列化与存储

提取的`NodeData`对象通过`JsonConvert.SerializeObject()`方法序列化为JSON字符串，并存入`Data_1_0.NodeList`列表中。`Data_1_0`类的`NodeList`属性是字符串列表，用于存储所有节点的序列化数据。

```mermaid
flowchart TD
A[NodeData对象] --> B["JsonConvert.SerializeObject()"]
B --> C{序列化成功?}
C --> |是| D[JSON字符串]
D --> E[添加到Data_1_0.NodeList]
C --> |否| F[处理异常]
F --> G[跳过当前节点]
G --> H[继续处理下一个节点]
```

## 反序列化与ID映射

在反序列化过程中，`Loader_1_0`类负责将存档数据重新加载到编辑器中。`LoadNodeList`方法解析`NodeData`字符串，创建相应的节点实例，并恢复其ID和坐标。ID映射在重建节点连接时起关键作用，确保连接线能正确指向目标节点。

```mermaid
sequenceDiagram
participant Loader as Loader_1_0
participant NodeData as NodeData
participant NodeBase as NodeBase
participant WM as WM.Main.Editer
Loader->>NodeData : JsonConvert.DeserializeObject()
NodeData-->>Loader : NodeData实例
Loader->>NodeBase : CreateNode()
NodeBase-->>Loader : 节点实例
Loader->>NodeBase : 设置ID和Point
Loader->>NodeBase : LoadParaDict()
Loader->>NodeBase : LoadPropertyDict()
Loader->>WM : LoadNode()
WM-->>Loader : 完成加载
```

## 自定义节点类型识别

自定义节点必须重写`GetTypeString()`方法以确保类型正确识别。该方法返回一个字符串标识符，用于在反序列化时创建正确的节点实例。`NodeLibManager`根据`NodeLibName`和`TypeString`来查找并创建相应的节点类型。
